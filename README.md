# Nizam — Releases

Windows installers and the auto-update feed for **Nizam**, a bilingual (Arabic / English) personal dashboard for tasks, expenses, calendar and habits. Everything runs locally on your device — no account, no server.

> This repository only hosts release files. The source code is private.

## Install

1. Open the **[latest release](https://github.com/Omar-Aqel/nizam-releases/releases/latest)** and download `Nizam-Setup-x.y.z.exe`.
2. Run it. Windows SmartScreen may warn because the installer is not code-signed: choose *More info → Run anyway*.
3. A **Nizam** shortcut is added to the Desktop and the Start menu.

## Updates

Installed copies update themselves: the app checks this repository shortly after launch and every few hours, downloads new versions in the background and shows an **"Update ready — Install now"** button. If you ignore it, the update installs the next time you close the app. Your data is kept across updates.

## What's inside

- Overview dashboard with today's priorities, schedule, budget health, spending by category, habits and notes
- Tasks, expenses (monthly budget, CSV export), calendar and habit streaks
- Pomodoro focus timer and `Ctrl + K` command palette
- 8 colour themes, 6 Arabic + Latin fonts, text size, light / dark mode
- JSON backup and restore

## Requirements

Windows 10 or 11, 64-bit.
